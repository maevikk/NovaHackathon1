# 06 · Глоссарий и методология KPI

| Термин | Определение / формула | Единица | Статус |

| Поток создания ценности | Сквозная совокупность преобразований сырья, материалов и информации в продукт для клиента (МУ-17, разд. 2) | — | Методика |
| КПСЦ | Карта связей **материального и информационного** потоков | — | Методика |
| CT / время цикла | Повторяемое время выполнения работником всех операций на рабочем месте; для партии = время изготовления / число единиц | сек/шт | Норматив CTн есть; CTф нет |
| CTн | Сумма секунд шагов рабочего стандарта | сек/шт | Подтверждено документом, не наблюдением |
| Такт | Фонд доступного времени / спрос | сек/шт | 1200/10 = **120 с/шт** |
| ФДВ | Фонд доступного времени с исключением регламентных перерывов | сек | В пилоте условно 1200 с; реальные перерывы уточнить |
| ВПП | Продолжительность **критического пути** с обработкой, ожиданием, транспортировкой (МУ-17, разд. 2) | сек, мин, дни | Нет измерений, фактическое ВПП неизвестно |
| НЗП | Все ещё не завершённые детали/подсборки на определённый момент | шт, ₽ | Не измерено |
| Потенциальное узкое место | Производственный ресурс с минимальной нормированной пропускной способностью | шт/ч | По исходным CTн риск №8 |
| Выпуск за смену | Сданные годные изделия за период | шт | Прогнозный результат модели; факт неизвестен |
| Пропускная способность | Выпуск за период / длительность периода | шт/час | Расчётная |
| Загрузка по модели | Сумма времени, когда станок/исполнитель занят / (время смены × число ресурсов) | % | Прогноз, не производственный анализ |
| Доля годной продукции | Число принятых клиентом / число предъявленных ×100% («Инфоцентр», стр. 10–11) | % | Требует наблюдений |
| Брак | Не принят по качеству; может предусматривать доработку | шт, % | Частота неизвестна; в демонстрации предполагается 0% |
| Себестоимость/прибыль | Выручка − затраты на запуски/труд/логистику/накладные | ₽ | Нет ставок; расчет не выполняется до ввода |
| FIFO | Обработка в порядке поступления | — | Принцип движения очереди |
| Супермаркет | Контролируемое место хранения по номенклатуре с правилами пополнения (МУ-17, прил. 4) | — | В модели концептуально |

**Важно:** `theoretical_critical_path_s` в API — **структурная нижняя оценка последовательных нормативных операций** без ожиданий. Это **НЕ ВПП**, даже если результат похож по смыслу на путь изделия.

**Не приравнивать** заданное количество 10 к фактической выработке, «отпущенные комплекты» к полному НЗП, нормативный CT к результату хронометража, модельную загрузку к подтверждённому OEE.
