# 07 · Реестр достоверности, допущений и ограничений

## Подтверждено документально

- Кейс учебной фабрики: пульт управления давлением газа, 9 сборочных операторов и отдельная контрольная операция; `0. Общее описание`, стр. 1–2 и `3. Стандарты`, стр. 33–50.
- Раунд 20 минут, план 10 изделий, такт 120 с, поставка через логиста, перемещение по 2 единицы; `0. Общее описание`.
- Нормативы по операциям (см. `source_reconciliation.csv`).
- Планировка 6,15 × 18,40 м, размеры стола 1,00 × 0,70 × 0,82 м, но без измеренного маршрута логиста.

## Принято **только для расчётного сценария**

| ID | Допущение | Причина | Риск для результата |

| A-01 | Каждое рабочее место получает необходимые комплекты со склада в начале моделирования | Есть карточки комплектации, но нет расписания подвозок | Завышенная доступность материалов |
| A-02 | Первоначальный НЗП = 0 | Наблюдений не предоставлено | Влияние «холодного старта» на выпуск |
| A-03 | Время рейса логиста = 0 секунд | Нет хронометража/маршрута | Прогноз выпуска завышает возможности реальной логистики |
| A-04 | Брак = 0% | Нет наблюдённой доли брака | Прогноз выпуска завышается |
| A-05 | Связи 1→2, 2+3→4, 4+5+6→7, 7→8→9→ОТК | Рабочие стандарты не являются полной маршрутной картой | Потенциально неверная логика сборки |
| A-06 | Все входы операции нужны для сборки одной единицы (AND join) | Для подсборок необходима синхронизация | Нужна BOM и число деталей на изделие |
| A-07 | Замеры нормативов равны неизменным временам работы | Детерминированное MVP | Нельзя моделировать вариативность и простои |
| A-08 | Клиент забирает по одному с интервалом такта | Условия первого раунда | Важно для факта принятия к концу смены |

## Неизвестно: **нельзя заменять вымыслом**

CTф и разброс циклов, реальные запасы/нормы задела, простои и причины, доработка/маршруты брака, движение по диаграмме спагетти, денежные ставки, доступное время с перерывами, подтверждение всех материальных переходов, происхождение каждой цены.

## Архитектурные ограничения

- Отсутствуют внешние интеграции ERP/MES/1С — по предварительному ТЗ.
- Сервер слушает только loopback; демо-авторизация с паролем не годится для публичного развёртывания и полноценного исполнения ФЗ-152.
- Материальный граф без циклов; возврат брака пока не поддерживается.
- Модель с AND join и перевозками партиями — упрощение; не моделирует промежуточные сервисные ресурсы, реальную топологию логиста и баланс денежных/материальных потоков.
- 3D-тур (направление B ТЗ) не реализован; только 2D-планировка.
